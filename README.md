# El Secreto del Sacré Coeur — Búsqueda del Tesoro AR

Juego web de realidad aumentada basado en marcadores, realizado con **AR.js 3.4.8** + **A-Frame 1.8.0**.

## Qué incluye

- 3 marcadores AR personalizados y distintos.
- Secuencia de juego: Inicio → Aula Magna → Capilla del Encuentro.
- Elementos 3D diferentes: brújula, llave y cofre.
- Eventos `markerFound` / `markerLost`.
- Progreso persistente con `localStorage`.
- Temporizador, vibración y sonido de feedback.
- Pantalla final con animación de confeti y código de finalización.
- `markers.html` listo para imprimir los marcadores físicos.
- Modo de prueba sin cámara para validar la lógica: `?debug=1`.

## Publicación en GitHub Pages

En **Settings → Pages**, elegir **Deploy from a branch**, rama `main` y carpeta `/ (root)`.

## Tecnologías

- A-Frame 1.8.0
- AR.js 3.4.8
- JavaScript ES6, HTML5 y CSS3
- Sin backend ni base de datos
